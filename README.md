# 🤖 AI Research Paper Analyzer

An AI-powered research paper analyzer built with Python, Streamlit, RAG, FAISS, Sentence Transformers, Llama 3.2, and Ollama.

This application allows users to upload a research paper in PDF format and ask questions about its content. The system retrieves the most relevant information from the paper and uses Llama 3.2 to generate context-based answers.

## 🚀 Features

- 📄 Upload research papers in PDF format
- 🔤 Extract text using PyMuPDF
- ✂️ Text chunking for efficient retrieval
- 🧠 Sentence Transformer embeddings
- 🔍 Semantic search using FAISS
- 🤖 Llama 3.2 local LLM
- 🔗 Retrieval-Augmented Generation (RAG)
- 💻 Local AI processing with Ollama
- 🎨 Interactive Streamlit interface
- 📚 Display retrieved source sections with page numbers
